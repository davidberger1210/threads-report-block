# Threads 檢舉＋封鎖小幫手

在 Threads 網頁版的個人主頁上，一鍵走完「檢舉 → 封鎖」那一串選單；可以貼一份帳號名單排成佇列，按 **J** 跳到下一個。
**每次只處理你正在看的這一個帳號，而且要你自己按下去才會動。** 不會自動批量掃射，不會替你決定誰該被檢舉。

> 適用：桌機瀏覽器（Chrome / Edge / Brave / Firefox）＋ Tampermonkey（篡改猴）。手機 App 不適用。

---

## 一、安裝 Tampermonkey（篡改猴）

Tampermonkey 是一個瀏覽器外掛，負責在特定網站上執行「使用者腳本」。本工具就是一支使用者腳本。

1. 開啟你瀏覽器的擴充功能商店，搜尋 **Tampermonkey**，或直接點：
   - Chrome／Edge／Brave：<https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo>
   - Firefox：<https://addons.mozilla.org/firefox/addon/tampermonkey/>
   - Safari：App Store 搜尋「Tampermonkey」
2. 按「加到 Chrome」（或對應按鈕）→ 確認安裝。
3. 安裝完成後，瀏覽器右上角會出現一隻猴子圖示。點它一下，確認狀態是「已啟用」。

**Chrome 使用者請多做一步（Chrome 138 以後必要）**：
網址列輸入 `chrome://extensions` → 右上角打開「開發人員模式」。
沒開的話 Tampermonkey 裝好了也跑不動腳本。

---

## 二、安裝本腳本

1. 點這個連結（Tampermonkey 會自動攔截 `.user.js` 結尾的網址）：

   **<https://github.com/davidberger1210/threads-report-block/raw/main/threads-report-block.user.js>**

2. Tampermonkey 會開一個新分頁，顯示腳本名稱、版本和它會在哪些網站上跑（只有 `threads.com` 與 `threads.net`）。
3. 按 **「安裝」**。
4. 之後有新版本時，Tampermonkey 會自動檢查並提示更新。

如果連結點了只顯示一堆程式碼而沒有跳出安裝畫面：
- 回到第一節確認 Tampermonkey 已啟用、Chrome 的「開發人員模式」已打開。
- 或手動安裝：點 Tampermonkey 圖示 → 「管理面板」→ 「＋」新增腳本 → 把整份程式碼貼進去覆蓋 → `檔案` → `儲存`。

## 三、使用方式

### 1. 打開某個帳號的主頁

到 `https://www.threads.com/@某帳號`，右下角會出現一個小面板「檢舉＋封鎖」。
不在帳號主頁時面板會提示「打開某個帳號的主頁才能操作」。

### 2. 選理由，按一下

| 面板元件 | 作用 |
|---|---|
| 理由下拉選單 | 五種檢舉理由：機器人／假帳號、垃圾訊息、仇恨言論、霸凌騷擾、詐騙 |
| **檢舉＋封鎖** | 替你點開「⋯」→ 檢舉 → 選理由 → 送出 → 再封鎖 |
| **只封鎖** | 跳過檢舉，只做封鎖 |
| **下一個 J** | 跳到佇列裡下一個還沒處理的帳號（鍵盤按 J 也行） |
| 逐步模式 | 勾起來時，每點一步都先跳出確認框。**第一次用請保持勾選**，看清楚它在點什麼 |

做完一個帳號後，面板會顯示處理結果，1.5 秒後自動跳到佇列的下一個主頁，**停在那裡等你看過再按**。

### 3. 貼名單（可選）

面板最下方「貼名單」展開後，一行一個帳號，格式任選：

```
https://www.threads.com/@abc123 假帳號，昨天洗版
@xyz_456 詐騙連結
```

帳號後面的文字會當作「理由備註」顯示在面板上，提醒你當初為什麼把它列進來。
沒寫備註的會標成橘色「未查證」。
按「載入（自動去重）」即可；若 Threads 擋住貼上，會改用瀏覽器原生輸入框讓你貼。

### 4. 從一篇貼文抓名單

在某篇貼文頁面（網址含 `/post/`）時，面板會出現「抓這篇貼文裡列的帳號」。
它只抓**貼文內文裡貼出來的 `threads.com/@xxx` 連結**，不抓作者、不抓留言者、不抓頭像。
適合用在「有人整理了一份名單貼出來」的情況。

## 四、它刻意不做的事

- **不自動連續處理**：每個帳號都要你親自按一下。冷卻時間 8 秒，按太快會被擋。
- **不內建任何名單**：沒有「預設黑名單」，名單只來自你自己貼的。
- **不把資料送到任何地方**：佇列和進度存在 Tampermonkey 本機儲存區，不離開你的電腦。
- **不處理手機 App**。

這些限制是設計，不是缺陷。目的是幫你把「本來就要做、只是要點很多下」的事變快，而不是做成一把自動掃射的槍。濫用檢舉功能可能違反 Threads 的社群守則，請自行判斷每一個帳號。

## 五、常見狀況

| 狀況 | 原因／處理 |
|---|---|
| 面板沒出現 | 確認 Tampermonkey 已啟用、Chrome 開發人員模式已開、網址是 `threads.com` 或 `threads.net` |
| 顯示「冷卻中，N 秒後再按」 | 正常，8 秒冷卻 |
| 跳出「這個頁面真的走丟了」 | 帳號已刪除或停權，腳本會記成「帳號不存在」並自動跳下一個 |
| 主頁上已經是「解除封鎖」 | 之前就封過了，按 J 會記成「已經封鎖過」直接跳過 |
| 點了理由沒反應 | Threads 偶爾改版面，請開 issue 附截圖（遮掉個人資訊） |
